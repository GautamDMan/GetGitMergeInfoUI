GetGitMergeInfo

local · read-only by default

Point this at a git repo on this machine, list the file names you care about, and get the last merge that touched each one — who merged it, who actually wrote the code, and every other merge of that same branch.

Repository

Local path to the one repository to search. No credentials needed — this never talks to a remote.

Leave blank to read the repo exactly as it sits on disk.

Results

File Merge owner Pushed by Merge message Branch Commit Merged at Other merges of this branch
Reads git history only — the same rules as the original CLI script: --merges --full-history so clean, non-conflicting merges aren't hidden by git's default path simplification.
